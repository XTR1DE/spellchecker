API сервис
<a href="/classifier/"><b>/classifier</b></a> - каталог с классификатором слов на Golang
отделяет текст от кода и прочих сущностей. При этом избегая моментов, где могут быть false positives (например скобки точки ";" "=" , которые могут быть восприняты как функция или метод) - следующий морфологический пункт должен отделить оставшиеся случаи от основного текста
<a href="/lexical/"><b>/lexical</b></a> - Python сервис для лемматизации слов. Находится процессе разработки

Оба серсиа общаются через API. общение с ними осуществляется через web интерфейс. Сервис отдающий интерфейс находится в /classifier
Интерфейс - инструмент отдалки. Он возвращает все. Даже то, что отсеивается - для удобства разработки

Запуск classifier - build+start.bat
Запуск lexical - check_advisory.py
Если оба сервиса запущены:
Интерфейс для загрузки текста поднимется на http://127.0.0.1:8080
Для простой проверки можно выполнить curl в cmd из System32:

curl.exe -i -X POST "http://127.0.0.1:8080/tokenize" -H "Content-Type: application/json" --data-raw "{\"text\":\"List duplicates are allowed // List\"}"
