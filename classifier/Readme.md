Classifier
Сервис на Golang
Все исходники в .go
Запуск через <a href="build+start.bat">build+start.bat</a> - он билдит из них исполняемые файлы для Win(.exe в /target/) и запускает

Первый файл - <a href="static+proxy.go">static+proxy.go</a> - отдает веб страницу + проксирует все запросы с 8080 на следующий сервис (8090)

Второй файл - <a href="classifier.go">classifier.go</a> - сервер (слушает 8090/tokenize). В него загружается весь текст. он производит классификацию и возвращает поток слов по мере обработки (с их границами и типом). 
Отдельно тип WORD проходит через сервис lexical для получения словоформ и дополнительной метки ib (true/false) - является ли словом из ИБ

classifier полностью классифицирует текст после чего все WORDs одним запросом отправляются в lexical. Отправлять в отдельный сервис по слову - невогодно - куча сетевых запросов увеличивают задержку.
Протестировано (<a href="/responce_time_benchmark/benchmark_check.py">benchmark_check.py</a>) - текст из 400 слов лучше отправлять весь, чем городить batch'и или по timeout отсылать
lexical Возвращает уже по мере обработки - и они последовательно уходят в responce/

в <a href="/static/example.txt">/static/example.txt</a> находится текст, который по умолчанию находится в поле ввода для теста - там содержится синтаксис всех поддерживающихся языков и тяжелые случаи
